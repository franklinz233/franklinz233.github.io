# Site typography

Gilda Display is used for section headings and the profile name.
DM Sans is used for body text, navigation, and publication titles.
Both fonts are distributed under the SIL Open Font License; licenses are included.

Font files were obtained from Google Fonts on 2026-10-09:

- https://fonts.google.com/specimen/Gilda+Display
- https://fonts.google.com/specimen/DM+Sans

The color palette and serif/sans-serif pairing are inspired by World Labs:
https://www.worldlabs.ai/case-studies/1-robotics
