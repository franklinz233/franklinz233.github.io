# FlexComposer project page

A responsive, dependency-free project page for "FlexComposer: Unified Video Compositing from Images to Dynamic Footage with Flexible Trajectory Control."

The page uses local paper figures and compact demo clips derived from the research materials in this workspace.

cd C:\Users\Franklin\Desktop\Paper\Sig_26\sol-attn-page
